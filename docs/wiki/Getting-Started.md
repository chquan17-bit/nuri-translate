# 시작하기

**Discord에 설치된 Nuri에서 메시지를 선택하거나 `/nuri`로 글을 입력하세요.**

## 1. 선택한 글 번역하기

1. 번역할 메시지를 우클릭하거나 모바일에서 길게 누릅니다.
2. **Apps** 메뉴에서 **Nuri 번역**을 선택합니다.
3. 요청자에게만 표시되는 번역과 원문을 확인합니다.

영어 글은 한국어로, 한국어 글은 영어로 번역합니다. 다른 언어의 글은 한국어로 번역하도록 모델에 요청합니다.

카드형 메시지는 Discord가 전달한 `content`, embed의 `title`·`description`·`fields` 텍스트를 합칩니다. 같은 텍스트 블록은 한 번만 포함하며, 멘션 문법은 번역 원문에서 제거합니다. 멘션만 있거나 읽을 텍스트가 없으면 모델을 호출하기 전에 안내합니다.

## 2. 표현을 익히기

**Nuri와 영어 배우기**를 선택하면 번역 뒤에 다시 사용할 영어 표현을 최대 2개 표시합니다. 번역과 학습 설명을 분리하고 원문을 함께 남겨 내용을 대조할 수 있습니다.

직접 입력할 때는 `/nuri`의 `text`에 글을 붙여 넣고 `mode`에서 번역 또는 영어 학습을 선택합니다.

## 3. 내 문장으로 연습하기

학습 결과의 **한 문장 써보기** 버튼을 누르고 영어 문장을 입력합니다. 자연스럽게 다듬은 문장과 가장 유용한 교정 설명 한 가지를 확인합니다. 버튼은 10분 뒤 만료되며, 만료되면 Nuri를 새로 실행해 시작합니다.

## 입력과 출력 기준

| 항목 | 기준 |
|---|---|
| 번역·학습 입력 | 합산 최대 3,000자 |
| 연습 문장 | 최대 1,000자 |
| 긴 출력 | UTF-16 기준 Discord 메시지 한도 안에서 최대 6개로 분할 |
| 읽지 않는 대상 | 이미지 내용, 첨부파일 내용, 링크의 외부 페이지 |
| 응답 공개 범위 | 요청자에게만 표시, 자동 멘션 비활성화 |

> [!NOTE]
> “나에게만 표시”는 Discord 응답의 공개 범위입니다. 번역할 텍스트는 처리를 위해 Google API에 전달됩니다. 자세한 범위는 [보안과 데이터](Security.md)를 확인하세요.

## 개발 환경에서 확인하기

Python 3.13과 `uv`를 준비한 뒤 저장소 루트에서 실행합니다.

```powershell
uv --cache-dir .state/uv-cache sync --frozen
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe -m nuri doctor
```

`doctor`는 비밀 값 존재 여부를 확인하며 외부 요청을 보내지 않습니다. `.env.example`은 환경 변수 이름을 보여 주는 예시이고 자동으로 로드되지 않습니다.

Windows의 `Configure-Nuri.cmd`는 로컬 복구용 비밀 값을 DPAPI로 암호화합니다. Cloud Run이 정상 운영 중이면 로컬 Gateway를 따로 시작할 필요가 없습니다. 새 Discord 앱으로 옮길 때는 환경 변수뿐 아니라 코드의 앱 ID 검증값도 함께 검토해야 합니다.

런타임은 Nuri 앱 전용입니다. 관리 스크립트의 앱 ID 설정을 바꾸어도 런타임의 고정된 앱 ID 검증값은 바뀌지 않습니다.
