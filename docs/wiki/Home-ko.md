# Nuri · 운영 가이드

**선택한 글을 번역하고, 다시 쓸 표현을 익히고, 내 문장으로 연습합니다.**

Discord · Python 3.13 · Cloud Run · Gemini

</div>

---

Nuri는 Discord에서 사용하는 개인 번역·영어 학습 앱입니다. 선택한 메시지나 직접 입력한 텍스트를 처리하고, 결과는 요청자에게만 표시합니다. 이 Wiki는 사용 방법부터 배포와 장애 대응까지 이어지는 운영 매뉴얼입니다.

> [!NOTE]
> [정식 GitHub Wiki](https://github.com/chquan17-bit/nuri-translate/wiki)에서 세 언어의 안내를 제공합니다. 소스와 문서를 공개해도 봇 사용 권한과 클라우드 설정은 바뀌지 않습니다. 운영 중인 봇은 소유자만 사용할 수 있고 결과는 요청자에게만 표시됩니다.

## 세 가지 사용 방식

| 기능 | 입력 | 결과 |
|---|---|---|
| **Nuri 번역** | 선택한 글 또는 직접 입력한 글 | 번역 → 원문 |
| **Nuri와 영어 배우기** | 선택한 글 또는 직접 입력한 글 | 번역 → 다시 쓸 표현 최대 2개 → 원문 |
| **한 문장 써보기** | 학습 결과의 버튼에서 입력 | 교정한 문장 → 핵심 설명 한 가지 → 내 문장 |

메시지 본문과 카드의 제목·설명·항목 텍스트를 함께 읽습니다. 이미지, 첨부파일, 링크의 외부 페이지를 자동으로 수집하지 않습니다.

## 현재 운영 원칙

| 항목 | 기준 |
|---|---|
| 실행 | 공개 HTTP ingress와 비공개 worker를 분리 |
| 접근 | Discord 요청 서명 검증, 소유자만 사용 |
| 서비스 크기 | 두 서비스 모두 요청 기반, 최소 0 · 최대 1, CPU 1 · 512 MiB |
| 사용량 | 하루 25회 · 요청 간 10초 · 모델 처리 동시 1개 |
| 중복 처리 | Firestore 예약 후 모델 호출, 동일 interaction의 재생성 방지 |
| 릴리스 | annotated tag의 깨끗한 소스에서 빌드, 동일 digest를 두 서비스에 배포 |

> [!IMPORTANT]
> 최소 인스턴스 0을 유지하므로 오랜 유휴 뒤 첫 요청은 시작 지연으로 Discord의 3초 응답 제한을 넘길 수 있습니다. 현재 운영에서 남아 있는 제한입니다.

## 문서와 릴리스 기록

Wiki의 원본은 저장소 `docs/wiki/`에서 관리합니다. 코드의 기본값과 현재 운영 설정을 구분하고, 실제 배포 결과는 릴리스별 commit SHA·build ID·image digest·revision 기록으로 확인합니다. 문서의 예시에는 실제 키, 개인 계정, 클라우드 프로젝트 식별자를 넣지 않습니다.

한국어 원본을 수정해 `main`에 반영하면 GitHub Actions가 변경된 본문을 영어와 중국어 간체로 번역하고 세 언어 Wiki를 함께 갱신합니다. 번역이나 링크 검증에 실패하면 기존 Wiki를 유지합니다. 작성 위치와 재실행 방법은 [문서 자동화 안내](../WIKI-AUTOMATION.md)를 참고하세요.
