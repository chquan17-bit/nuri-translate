# Nuri · 使用与运维指南

**翻译所选文字，掌握实用表达，再用自己的句子练习。**

Discord · Python 3.13 · Cloud Run · Gemini

Nuri 是用于 Discord 的个人翻译与英语学习应用。它处理用户选择的消息或直接输入的文本，结果仅对请求者可见。本 Wiki 涵盖日常使用、版本部署和故障排查。

> [!NOTE]
> 本 Wiki 以仓库内文档的形式提供。当前套餐不支持该私有仓库的 GitHub Wiki 标签页；发布文档时未变更套餐或仓库可见性。

## 三种使用方式

| 功能 | 输入 | 结果 |
|---|---|---|
| **Nuri 번역（Nuri 翻译）** | 所选消息或直接输入的文字 | 翻译 → 原文 |
| **Nuri와 영어 배우기（跟 Nuri 学英语）** | 所选消息或直接输入的文字 | 翻译 → 最多 2 个实用表达 → 原文 |
| **한 문장 써보기（试写一句话）** | 通过学习结果中的按钮输入 | 修改后的句子 → 一项重点说明 → 自己的原句 |

应用会一起读取消息正文以及卡片的标题、描述和字段文字，不会自动抓取图片、附件或链接指向的外部网页。

## 当前运行原则

| 项目 | 标准 |
|---|---|
| 执行方式 | 公开 HTTP ingress 与私有 worker 分离 |
| 访问控制 | 验证 Discord 请求签名，仅允许配置的所有者使用 |
| 服务规格 | 两个服务均按请求计费，最少 0 / 最多 1 个实例，1 CPU / 512 MiB |
| 用量 | 每天 25 次、请求间隔 10 秒、同时执行 1 个模型请求 |
| 防止重复 | 调用模型前在 Firestore 中预约，防止同一 interaction 重复生成 |
| 发布 | 从附注标签的干净源码构建，将相同 digest 部署到两个服务 |

> [!IMPORTANT]
> 最少实例数保持为 0。长时间空闲后的首次请求可能因启动延迟而超过 Discord 的 3 秒响应期限。这仍是当前运行方式的已知限制。
